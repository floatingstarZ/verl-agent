\section*{Scope}
当前 StepPPO-v3 的工程改动只服务一个目标：在 GiGPO 训练中加入 shared value head，验证 value head 是否能稳定学习 step-level return，并确认它不影响 GiGPO policy 训练。

因此 v3 的默认改动不是新 estimator，不是新 advantage，不是 action-level PPO。v3 默认改动表如下：
\begin{center}
\begin{tabular}{@{}p{0.30\linewidth}p{0.32\linewidth}p{0.28\linewidth}@{}}
\toprule
模块 & GiGPO baseline & StepPPO-v3 当前分支 \\
\midrule
policy advantage & GiGPO & 不变 \\
policy loss & vanilla token-level PPO path & 不变 \\
rollout group & GiGPO group & 不变 \\
actor model & actor LM & actor LM + value head \\
value target & 无 & step GAE return \\
value gradient & 无 & 默认只更新 value head \\
验收目标 & policy performance & value 稳定学习且不伤 policy \\
\bottomrule
\end{tabular}
\end{center}

\section*{复用的现有路径}
当前 v3 应复用已有 GiGPO-v1 value-aux 路径：
\begin{lstlisting}
verl/trainer/ppo/gigpo_v1_value_aux_trainer.py
examples/gigpo_v1_value_aux_trainer/run_webshop.sh
verl/workers/actor/value_head.py
verl/workers/actor/step_ppo_actor.py
verl/workers/gigpo_v1_value_aux_fsdp_workers.py
verl/workers/sharding_manager/step_ppo_filters.py
\end{lstlisting}

关键逻辑：
\begin{enumerate}
  \item trainer 保持 \path{algorithm.adv_estimator=gigpo}；
  \item trainer 构造 value head 的 step GAE return，并写入 \path{data.batch["step_returns"]}；
  \item actor 看到 \path{step_returns} 后启用 auxiliary value loss；
  \item sharding manager 同步 rollout 权重时过滤 \path{value_head.*}。
\end{enumerate}

\section*{新增指标}
需要在 \path{verl/workers/actor/step_ppo_actor.py} 中补充 value diagnostics：
\begin{lstlisting}
value_error = current_values - step_returns
value_rmse = sqrt(mean(value_error ** 2))
value_mae = mean(abs(value_error))
value_explained_variance = 1 - var(step_returns - current_values) / var(step_returns)
\end{lstlisting}

训练日志应出现：
\begin{lstlisting}
actor/value_rmse
actor/value_mae
actor/value_explained_variance
actor/value_pred_std
actor/value_return_std
\end{lstlisting}

这些指标用于判断 value head 是否学到 signal，而不是只判断 value loss 数值是否下降。

\section*{DataProto 字段}
当前 v3 需要的字段：
\begin{lstlisting}
data.batch["advantages"]          GiGPO policy advantage; keep unchanged
data.batch["state_values"]        old value prediction, shape [batch]
data.batch["step_returns"]        value target, shape [batch]
data.batch["value_step_rewards"]  reward used for value target diagnostics
\end{lstlisting}

当前不需要新增 \path{step_advantages} 进入 policy loss。只要 policy advantage 改了，就不是当前 v3。

\section*{不要做的改动}
除非用户明确要求新版本，不要在当前 v3 默认路径中加入：
\begin{itemize}
  \item \path{algorithm.adv_estimator=step_ppo_v3}；
  \item pure step advantage；
  \item action-level PPO ratio；
  \item \path{policy_loss.loss_mode=action_level}；
  \item separate critic；
  \item value loss 默认更新 actor backbone。
\end{itemize}
